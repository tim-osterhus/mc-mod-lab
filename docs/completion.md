The alpha finishes independently of the Aura port. Source publication is already
authorized; global installation and public directory submission are separate.

## Implemented before this completion pass

- Explicit Windows process, loopback/authentication, game directory, world path,
  player mode, fixture marker, bridge hash, and memory checks.
- Fresh disposable copies, bounded GUI actions, before/after PNG and JSON/Markdown
  capture, honest failure states, and preserved independent visual review.
- Pinned v0.3.0 upstream source and five patches covering three bridge classes.

## Intentionally unsupported

Production intermediary JARs, other Minecraft versions/loaders, multiplayer,
stock unauthenticated MCP transport, automatic launch/build/process teardown,
generic command execution, destructive reset, dashboards, multiple adapters,
and automatic visual/parity approval are outside this alpha. These compatibility
and authority limits do not depend on completing Aura.
