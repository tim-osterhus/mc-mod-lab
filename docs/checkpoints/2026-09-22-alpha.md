## Portable toolkit and installation

- Parity/report schemas enforce dated provenance, artifact hashes, relative paths,
  independent check dimensions, and a reviewer for visual conclusions.
- The offline replay reproduces the same failure/correction assertion with
  deterministic synthetic images. It cannot support a live-client pass.
- The identity example includes the required port, with a regression test covering
  all required identity fields.
- An explicit file allowlist produces deterministic plugin ZIPs. Upstream MIT
  attribution is included; runtime binaries, worlds, credentials and media are
  excluded.
- A fresh isolated installation passed on Codex CLI 0.153.4. A new local app-server
  discovered the enabled skill from its installed cache, and that installed CLI
  ran and validated the portable replay from a different working directory.
  Normal config/marketplace fingerprints were unchanged. No model or game session
  was started by this test.

The supported live profile remains Windows/Fabric 1.21.1 Mojmap development.
Production intermediary JARs and other loaders are unproven compatibility targets.
Normal-profile installation and public directory submission remain separate
operator decisions. Completion of the toolkit alpha does not claim Aura parity.
