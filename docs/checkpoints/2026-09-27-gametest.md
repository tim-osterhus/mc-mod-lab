# Milestone 4: real Fabric GameTest conservation

The scoped deterministic lane is implemented and has run against the exact
packaged 1.21.1 Aura 0.2.1 release, without building or editing the current
Aura source tree. Milestones 1-3 retain their separate five-case client gate.
This checkpoint does not finish the entire Mod Lab spec: milestone 5 and broader
Aura coverage remain later work, including the known juvenile Breeder defect.

## Implementation

- `gametest-src/lab/gametest/AuraTransferTests.java`: real Fabric GameTest
  entrypoint using pinned intermediary classes, a single initial-input injection,
  81 server-tick observations, loaded-mod origin evidence, and actual world tickers.
- `scripts/build_gametest_adapter.py`: Java 21, local inputs only, fixed API/release
  bytes, no annotation processors, stable adapter ZIP entries.
- `gametest_runtime.py`: fresh isolated headless profile, explicitly reviewed
  executable inventory, symlink/reparse refusal, filtered child environment,
  owned-process cleanup, sampled 3800 MiB memory and 180-second time guards.
- `gametest_import.py`: strict XML/identity/lifecycle/conservation import into
  the existing parity ledger, with client and visual dimensions left `not_run`.
  `contracts.py` re-imports the evidence when validating that deterministic record.

The [usage guide](../gametest.md) specifies input provenance and scope. Runtime
files, JARs, logs and worlds remain ignored/local. No third-party mod download
or binary redistribution was used. The manifest pins 45 existing executable
inputs; the separately reviewed adapter is the 46th. Extra files in the source
server directory are not discovered or copied into the executable profile.

## Failure history and limits

The first trial reached a conserved 115/885 state but crashed in Fabric's XML
writer because a bare output filename had no parent directory. It remains
unaccepted. The runtime now uses `evidence/gametest.xml`. Earlier exploratory
02/03/04 runs are retained separately; the final acceptance above uses the
explicit reviewed profile, loaded identities, lifecycle time bound, and final
adapter consistently.

Contract tests cover malformed or inconsistent XML, wrong loaded identities,
missing disclosure/ticks, incorrect conservation, absent transfer, evidence
tampering, wrong failure/exit, and forbidden client/visual promotion. Runtime
staging/cleanup tests are separate from the live GameTests. Hosted CI validates
Python/package contracts, not Minecraft gameplay; the proprietary runtime is
not uploaded to CI or bundled in the plugin.

Final local validation: 201 Python tests passed with 3 host symlink-privilege
skips; mocked reparse-point rejection remains covered. The release audit passed
97 staged/tracked files and 77 explicit package files. Independent Luna review
caught and corrected a parity-import bypass: a completed
`aura.conserved-transfer.gametest` record now requires the typed GameTest JSON
report, not a correctly hashed unrelated text/JSON artifact. All three final
live records were revalidated after that fix. Parent independently confirmed
the positive/control/repeat outcomes. No owned JVM remains running.

Only this declared Fabric 1.21.1 ordinary White transfer/obstruction test is
supported. Other GameTest suites, recipes, save-state cases, colors, versions,
client rendering, multiplayer and autonomous Survival are not inferred passed.
Milestone 5 remains later/deferred, not part of this batch.
